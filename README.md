# Infusions Tech App

Company website / installable web app for Infusions Tech, built with Next.js.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Edit content

All company text, phone, email and social links live in `lib/data.js`.

## Deploy

Push to GitHub and import the repo in Vercel (Framework preset: Next.js). No environment variables needed.
